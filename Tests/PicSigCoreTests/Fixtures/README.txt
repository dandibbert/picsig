paragraph-page.gray is an 8-bit grayscale bitmap: 96 pixels wide, 2800 pixels high, row-major, top-left origin. It was rasterized from a 600-pixel-wide white page using ordinary 22-pixel Latin text and narrowed horizontally without reducing its vertical resolution. It contains numbered, partly repetitive paragraphs and wide blank gaps. The test checks exact overlap translations for six viewport offsets (73, 420, 660, 841, 946, 1011). This is generated test content, not a user screenshot. No font files are included. UIKit/Vision and actual iPhone interaction require the separate iOS tests.
